# Palimpsity — Living Layers

An independent variant of River Pact: modular buildings up to four levels, building conversions, sculpted terrain and shared-basin river quays. Classic city and First Neighbourhood remain playable.

Automatically produced by LOB7 Enhancement. Implemented with Kimi and reviewed by Nilo; original Cédric, Codex, Claude and Kimi credits and licenses are preserved in CREDITS.md, LICENSE and THIRD_PARTY_NOTICES.md.
